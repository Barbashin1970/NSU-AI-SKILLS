# gost-19 — семейство навыков по ЕСПД для агента

Шесть навыков, которые учат агента (Claude Code, Codex) **писать комплект программной
документации по ГОСТ 19 (ЕСПД) так, чтобы его приняли** — и так, чтобы он не устаревал
молча.

Это не пересказ стандартов. Стандарты говорят, какие документы бывают и из каких разделов
состоят; они молчат о том, что убивает комплект на приёмке: числа, которые разошлись
с изделием; ведомость, в которой документ назван написанным, а он проект; содержание
без номеров листов; одиннадцать PDF с одинаковым именем; документ, который правили
после спецификации и тем сделали её неполной. Здесь собрано именно это.

**Главное правило, из которого выводится всё остальное:**

> Каждое число в документе несёт команду, которой оно получено. Число, набранное руками,
> устаревает при первой же правке кода — и устаревает **молча**: проверяющий видит
> стройную таблицу, не соответствующую тому, что лежит на диске.

## Навыки

| Навык | О чём |
|---|---|
| `gost-19` | Хаб: карта стандартов, коды видов документов, обозначения и редакции, работа с агентом |
| `gost-19-komplekt` | Состав комплекта: что писать, в каком порядке, шапки, состояние документа, изменения |
| `gost-19-dokumenty` | Что кладётся внутрь каждого вида: ТЗ, ПЗ, описание программы, текст программы, руководства, спецификация |
| `gost-19-sverka` | Числа, сверяемые с диском: опись, контрольные суммы, проверки-сторожа, ритуал перед поставкой |
| `gost-19-pechat` | Оформление и печать: ГОСТ 19.105/19.106, постраничная вёрстка в браузере, PDF, docx |
| `gost-19-priyomka` | Программа и методика испытаний, протокол, трассировка требований задания |
| `gost-19-primery` | **Живые образцы**: настоящий сданный комплект из одиннадцати документов целиком |

Седьмой навык — не текст о документах, а сами документы. Шаблон с многоточиями
не показывает главного: какого объёма бывает раздел, насколько подробно формулируется
требование, как выглядит честно названный отказ. Образец показывает.

## Установка

```bash
git clone <адрес-репозитория> gost-19-skills
cd gost-19-skills
```

**macOS / Linux:**
```bash
chmod +x install.sh && ./install.sh
```

**Windows (PowerShell):**
```powershell
./install.ps1
```

Затем **перезапустите Claude Code / Codex**, чтобы он подхватил навыки.

Установщик делает ссылки (симлинки на Unix, junction-каталоги на Windows), а не копии, —
поэтому `git pull` обновляет навыки сразу у всех агентов на машине. Навык, чьё имя
в целевом каталоге уже занято, **пропускается**: чужое не затирается.

**Вручную:** скопируйте каталоги из `skills/` в `~/.claude/skills/` (Claude Code)
и/или `~/.agents/skills/` (Codex). Сборки нет — навык это папка с файлом `SKILL.md`.

> Устройство репозитория и сценарии установки повторяют
> [apple-design-skills](https://github.com/) (MIT): раскладка `skills/<имя>/SKILL.md`
> плюс `references/`, установка ссылками сразу в два каталога агентов.

## Соглашение о пометках

В текстах навыков у каждого нетривиального утверждения стоит его происхождение.
Это не оформление: разница между буквой стандарта и чьим-то решением — первое, что
спрашивают на нормоконтроле.

| Пометка | Что означает |
|---|---|
| **[ГОСТ]** | Требование стандарта. Проверяется по тексту ГОСТа, ссылка на пункт приведена |
| **[практика]** | Решение, которое стандарт не предписывает и не запрещает. Приведён довод |
| **[замер]** | Проверено опытом, названы дата и условия. Со временем может перестать быть верным |

Пометка **[замер]** особенно важна там, где речь о браузерах: поддержка постраничной
вёрстки меняется, и утверждение «этого нельзя» верно на дату замера, а не навсегда.

## Откуда это взялось

Навыки собраны на живой работе: комплект из одиннадцати документов ЕСПД к программному
изделию для управления строительными проектами (Центр искусственного интеллекта НГУ,
2026 год). Комплект писался вместе с изделием, печатался, проходил внутреннюю приёмку
и правился по её замечаниям; отсюда и перечень граблей.

**Комплект опубликован целиком** — в навыке `gost-19-primery`, одиннадцать документов
как они есть. Техническое задание приведено **обезличенным**: из него сняты титульная
часть с листом утверждения, наименования сторон, должности и фамилии, номер договора,
адрес площадки внедрения и список научных статей; разделы, требования и формулировки
оставлены как в подлиннике. В остальных десяти документах персональных данных,
доступов и сведений о третьих лицах нет — проверено поиском перед публикацией.

Примеры внутри самих навыков построены на условном обозначении `АБВГ.00001-01`,
чтобы их можно было переносить на свой проект не задумываясь.

**Текстов ГОСТов здесь тоже нет.** Стандарты распространяются своим порядком; навыки
их не воспроизводят, а ссылаются на пункты. Перед сдачей комплекта сверяйтесь
с действующей редакцией стандарта — часть ГОСТов серии 19 менялась.

## Чего эти навыки не делают

* **не заменяют нормоконтроль.** Они доводят комплект до состояния, в котором
  нормоконтролёру есть что проверять, а не до «принято автоматически»;
* **не пишут документ за вас целиком.** Документ, сгенерированный без замеров
  и без изделия под рукой, читается как реферат и отклоняется первым;
* **не покрывают ГОСТ 34 и ГОСТ 2.** ЕСПД (серия 19) — про программные изделия;
  автоматизированные системы (серия 34) и конструкторская документация (серия 2)
  устроены иначе, и смешивать их нельзя.

## English summary

**gost-19 skills** — a six-skill family teaching an agent to produce a
**GOST 19 / ESPD** software-documentation set (the Russian software documentation
standard family, still mandatory for state-funded and many enterprise projects
in Russia and the CIS).

The skills cover: the map of the standards and document-type codes; designations and
editions; what belongs inside each document; **making every number in a document
verifiable against the repository** (inventories, checksums, guard tests, a
pre-delivery ritual); typesetting and printing to PDF (what CSS Paged Media can and
cannot do in browsers as of late 2026 — and the docx route); and the test-programme,
protocol and requirement-traceability side of acceptance.

The material is in **Russian**, because GOST 19 is a Russian-language standard family
and so is every document produced under it. Skill descriptions carry English keywords
so an agent routes correctly regardless of the prompt language.
