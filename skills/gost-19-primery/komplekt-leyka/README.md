# Комплект программных документов LEYKA (ЕСПД, ГОСТ 19)

**Обозначение изделия:** LEYKA.
**Изделие:** LEYKA — система управления проектами центра искусственного интеллекта НГУ.
**Дата:** 26.10.2026.

---

## Обозначения

Виды документов — по ГОСТ 19.101-77, структура обозначения — по ГОСТ 19.103-77: обозначение
программы, затем номер вида документа. Спецификация по ГОСТ 19.202-78 обозначается обозначением
самой программы, без номера вида.

**Обозначение говорящее — `LEYKA-NN`**, как у комплекта РАГРАФ (`РАГРАФ-ФРЕЙМ-NN`); решение владельца
от 26.10.2026. ГОСТ 19.103-77 допускает буквенный код организации-разработчика. Если состоится
государственная регистрация программы, обозначение заменяется присвоенным — один раз, во всём
комплекте сразу.

**Два задания — два документа одного вида, а не две редакции.** `LEYKA-1` — задание на программу,
`LEYKA-1/2` — на подсистему «Отчётность по Программе Центра»; вторая часть — номер документа данного
вида по ГОСТ 19.103-77. Косую черту в имени файла не записать, поэтому файл второго задания называется
«LEYKA-1 Техническое задание (подсистема отчётности).md», а обозначение `LEYKA-1/2` стоит в его шапке.

**Прежние обозначения.** До 26.10.2026 документы обозначались `ЦИИ НГУ.LEYKA.<вид>.<номер>-2026`,
программа — `ЦИИ-НГУ-LEYKA-2026`. В рабочих документах (`docs/*-RAZBOR.md`, `docs/BEKLOG.md`,
`docs/UGT/`) и в комментариях кода остаются прежние короткие имена «ТЗ.001» и «ТЗ.002».

## Сопутствующие документы — вне комплекта

Папка [VNE-KOMPLEKTA](VNE-KOMPLEKTA/README.md): инструкция по установке, выбор СУБД
и развёртывание, тест-план, инструкции по выкладке, архитектура для новичков, пользовательские
истории. Они нужны рядом с комплектом, но в счёт его документов не идут: комплект объявлен числом
в спецификации и программе испытаний, а документ, положенный к нему в каталог, это число молча
увеличил бы.

## Рабочие документы разработки — не здесь

`docs/BEKLOG.md` (бэклог отложенного), `docs/USE-CASES.md` (сценарии), `docs/*-RAZBOR.md` (разборы
с решениями), `docs/UGT/` — рабочие документы разработки по навыку skicoding. Из них берутся основания
решений для пояснительной записки, но в комплект они не входят. `docs/SKILL-*.md` — рабочие материалы
разработки: интерфейс, диаграммы, релиз, OAuth.
