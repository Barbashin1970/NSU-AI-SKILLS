# Содержание с номерами листов

**[ГОСТ]** 19.106-78 требует, чтобы в содержание входили наименования разделов
**и номера страниц**. При печати из браузера это единственное требование, которое
нельзя закрыть автоматикой. Ниже — почему и что делать.

## Почему браузер не может проставить номера

Чтобы написать в содержании «раздел 4 — лист 12», нужно **знать, на какой лист попадёт
раздел 4**, то есть разбить документ на листы заранее. В постраничной вёрстке CSS для
этого есть `target-counter()`:

```css
.soderzhanie a::after { content: target-counter(attr(href), page); }
```

**[замер] 15.09.2026: не поддержан ни одним браузером.** Ни Chrome, ни Firefox,
ни Safari. Правило принимается и молча ничего не выводит.

Своими силами задачу решает только **собственный разбиватель на листы**: измерять
высоту блоков, набирать листы, знать, где кончился лист. Это движок вёрстки ради одной
колонки — недели работы и постоянная поддержка.

## Три пути

| Путь | Стоимость | Когда выбирать |
|---|---|---|
| **Полумера: пустая колонка «Стр.»** | ноль | комплект печатают один-два раза |
| **Выгрузка в docx** | час-два на настройку | заказчику нужен docx; комплект переиздаётся |
| **Свой разбиватель** | недели | комплект печатается пачками и постоянно |

## Полумера, которая не выглядит недоделкой

Содержание оформляется **таблицей из двух колонок без рамок**: слева пункты, справа
пустая колонка под номер, шапка справа — «Стр.».

```markdown
|  | Стр. |
|---|---:|
| 1. Введение |  |
| 2. Назначение разработки |  |
| · 2.1. Функциональное назначение |  |
| 3. Требования к программному изделию |  |
```

```css
.markdown h2#содержание + table,
.markdown h2#содержание + table td,
.markdown h2#содержание + table th { border: 0; }
.markdown h2#содержание + table td:last-child { width: 15mm; }
```

Три свойства, которые делают её приличной:

1. **рамок нет** — ГОСТ линий не требует, а на листе они превращают перечень
   в ведомость;
2. **колонка подписана «Стр.»** — видно, что место оставлено намеренно;
3. **подпункты помечены** (`·` или отступом) — видна вложенность.

**Скажите об этом прямо.** В комплекте должно быть записано — в проверке, в пояснении
или в самом документе, — что колонка заполняется по готовой распечатке. Иначе следующий
человек примет пустую колонку за недоделку и потратит день на поиски автоматики,
которой нет.

**Дополнительная польза, не шуточная:** вписывая номера, человек **пролистывает
документ целиком** и видит его глазами — то, чего не делает ни один генератор.

## Проверка-сторож

Полумера требует сторожа: место под номер обязано быть **у каждого** документа
комплекта. Содержание без колонки в одном документе из одиннадцати — замечание
на приёмке.

```python
@pytest.mark.parametrize("put", KOMPLEKT, ids=lambda p: p.name[:28])
def test_soderzhanie_tablicey_s_kolonkoy_pod_nomera(put):
    html = _soderzhanie(put)
    assert "<table>" in html, f"{put.name}: содержание не таблица"
    assert html.count("<th>") == 2, "колонок должно быть две"
    assert "Стр." in html, "колонка номеров не подписана"
    ryady = re.findall(r"<tr><td>(.*?)</td><td>(.*?)</td></tr>", html, re.S)
    zanyatye = [(p, n) for p, n in ryady if n.strip()]
    assert not zanyatye, f"в колонке номеров что-то напечатано: {zanyatye[:2]}"
```

Последнее условие — не придирка: **заполненная ячейка означает номер, которого никто
не считал**. Такой номер хуже пустой клетки, потому что ему верят.

## Ссылки в содержании

Если документ читают и на экране, содержание стоит сделать ссылочным: пункт — ссылка
на якорь заголовка. Тогда одно содержание обслуживает оба вида — на экране по нему
переходят, на бумаге вписывают номер.

**Якоря** порождаются отрисовщиком из текста заголовка. Два подводных камня:

* якорь меняется при переименовании заголовка — ссылки гниют молча (сторож из
  `gost-19-sverka/references/storozha.md`, пункт 6);
* кириллические якоря по-разному обрабатываются отрисовщиками; проверяйте своим.

## Когда всё-таки писать свой разбиватель

Признаки, при которых недели работы окупаются:

* комплект переиздаётся ежемесячно и печатается десятками экземпляров;
* документов больше двадцати;
* заказчик требует не только номера листов, но и **живой колонтитул** с названием
  текущего раздела (`string-set` тоже не поддержан).

Опорный приём: `Range.getClientRects()` даёт координаты строк, по ним набираются листы.
Прежде чем начинать — посчитайте, во сколько обходится путь через docx.
