# Постраничная вёрстка в браузере: рабочие правила

Всё ниже проверено на Chrome 131+ в сентябре 2026 года на комплекте из одиннадцати
документов. Поддержка постраничной вёрстки меняется — перепроверяйте пометки **[замер]**.

## Лист, поля, подпись

```css
@page {
    size: A4;
    margin: 20mm 15mm 22mm 25mm;   /* верх, право, низ, лево */

    @bottom-center {
        content: counter(page) " / " counter(pages);
        font-family: "Times New Roman", "Liberation Serif", serif;
        font-size: 10pt;
        color: #000000;
    }
}
```

**Левое поле шире прочих** — под подшивку. Нижнее шире верхнего — под подпись листа.

**[замер] 15.09.2026.** В Chrome 131+ работают все шестнадцать полей-боксов
(`@top-left`, `@bottom-right` и прочие), и внутри них — счётчики `counter(page)`
и `counter(pages)`. Это ровно то, чего раньше не хватало: подпись ставит движок печати,
на каждом листе, не трогая текст документа.

## Подпись с именем документа

Имя разное у одиннадцати документов, а таблица стилей одна. Решение: страница
**дописывает правило** при показе документа.

```js
function podpisatListy(obozn, imya, redakciya) {
  var prezhnee = document.getElementById("podpis-lista");
  if (prezhnee) { prezhnee.remove(); }
  var podpis = (obozn + " · " + imya
                + (redakciya ? " · ред. " + redakciya : ""))
    .replace(/\\/g, "\\\\").replace(/"/g, '\\"');   // имя попадает внутрь строки CSS
  var stil = document.createElement("style");
  stil.id = "podpis-lista";
  stil.media = "print";
  stil.textContent =
    '@page { @bottom-center { content: "' + podpis + ' · " counter(page)'
    + ' " / " counter(pages); font-family: "Times New Roman", serif;'
    + ' font-size: 10pt; } }';
  document.head.appendChild(stil);
}
```

**Экранирование обязательно.** Имя документа попадает внутрь строки CSS; кавычка в имени
оборвала бы строку и испортила правило целиком — лист вышел бы без подписи, и заметили бы
это на бумаге.

**Запаска в таблице стилей.** Оставьте в CSS подпись с одним номером листа: если сценарий
не отработал, номер без имени лучше пустого низа.

## Разделы с новой страницы

```css
.dokument h2 { break-before: page; page-break-before: always; }
.dokument h2:first-of-type { break-before: auto; page-break-before: auto; }
```

Второе правило существенно: без него первый раздел уезжает на второй лист, оставляя
первый почти пустым.

**Черта перед заголовком.** Если в исходном тексте разделы отбиты `---`, в печати она
лишняя — разрыв листа уже разделил. Снимается правилом с `:has()`:

```css
.markdown hr:has(+ h2) { display: none; }
```

Тематические черты внутри разделов при этом остаются.

## Кегли и интервалы

**[практика]** Значения, прошедшие нормоконтроль:

| Элемент | Кегль | Замечание |
|---|---|---|
| основной текст | 12pt | интерлиньяж 1,4 |
| заголовок раздела (h2) | 14pt, прописные | |
| подзаголовок (h3) | 12pt полужирный | |
| таблицы | 10–11pt | иначе не помещаются |
| подпись листа | 10pt | |
| код и примеры | 9–10pt, моноширинный | переносить по словам |

Шрифт — с засечками (Times New Roman, Liberation Serif): это ожидаемый вид документа
по ГОСТ, и он же лучше читается на бумаге.

## Таблицы

```css
.markdown table { table-layout: fixed; width: 100%; border-collapse: collapse; }
.markdown td, .markdown th { word-wrap: break-word; padding: 1mm 2mm; }
```

`table-layout: fixed` — единственный способ заставить широкую таблицу уместиться:
иначе браузер растягивает её по содержимому и обрезает справа. Обрезанная таблица
в PDF не видна тому, кто печатал: на экране она помещалась.

**Правило проверки:** перед сдачей пролистать PDF целиком, глядя на правый край.

## Печать всегда чёрным по белому

```css
:root {
    color-scheme: light !important;
    --fon: #ffffff;
    --tekst: #000000;
}
body { background: #ffffff !important; color: #000000 !important; }
```

Иначе документ, открытый в тёмной теме, печатается серым по серому либо с чёрными
плашками — в зависимости от настройки «печатать фон».

## Чего нельзя (на дату замера)

| Приём | Состояние | Следствие |
|---|---|---|
| `target-counter(attr(href), page)` | не поддержан ни одним браузером | номера листов в содержании автоматически не проставить |
| `string-set` + `content: string(...)` | не поддержан | живой колонтитул с названием текущего раздела недоступен |
| свой колонтитул через `position: fixed` | разрешается браузерами по-разному | **[замер] 12.09.2026:** блок встал не внизу, а вверху листа и накрыл заголовок |
| `@page :first` для особого первого листа | частично | проверять на своём браузере |

Возвращать «свой колонтитул на `position: fixed`» после провала — типичная ошибка:
приём не станет работать от повторной попытки. Либо поля страницы (Chrome 131+),
либо путь через docx (`drugie-puti.md`).

## Что проверить глазами перед сдачей

1. первый лист не пустой и не начинается со второго раздела;
2. правый край: не обрезана ли таблица;
3. схемы читаемы;
4. подпись листа на **каждом** листе, номера сквозные, «N / M» сходится;
5. колонтитул браузера выключен — сверху нет адреса и даты;
6. имя сохранённого файла осмысленно и открывается на чужой машине;
7. содержание совпадает с фактическими заголовками.
